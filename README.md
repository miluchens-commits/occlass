# OC class

給小學生使用的可愛班級管理網頁（繁體中文）。目前已包含第一版班級管理、第二版作業與資產系統、第三版的服飾商店、寶箱、五種能力與服飾增益，以及第四版每位學生專屬的 3D「OC 房子」、家具建造與第一人稱探索。

## 執行方式

```bash
npm install
npm start
```

開啟瀏覽器進入 <http://localhost:3000>

- 資料存放在伺服器端的 `data/db.json`，重新整理、關閉瀏覽器、重啟伺服器後資料都不會消失。
- 可用環境變數 `PORT` 指定連接埠，`DB_FILE` 指定資料檔位置，`RESET_CODE` 指定重設代碼（預設 `OC-RESET-2026`）。
- 每次重新整理或登出都會回到「教師登錄／學生登錄」，班級與學生資料不會因此消失。

## 使用流程

1. **初始設定**：輸入年級與班級 → 按「確認」。已建立的班級會自動保留，不需要重新設定。
2. **身分選擇**：教師登錄 / 學生登錄。
3. **教師第一次登入**：設定教師密碼（至少 10 個字元），系統會顯示一次性的帳號恢復代碼。
   之後登入只需輸入密碼；密碼最多可成功修改 2 次，忘記密碼可用恢復代碼重設。
4. **建立班級**：輸入班級代碼（例如 508）與學生人數（例如 28），系統自動建立座號與五位數登入號碼。
5. **教師管理畫面**：顯示全班卡通人物，人物會穿著學生目前穿戴的服飾。
   點人物可看座號、登入號碼、等級、金幣／鑽石、五種能力與目前穿戴。
6. **學生登入**：輸入班級代碼與自己的五位數登入號碼，進入個人畫面。

## 第三版功能

### OC 金幣兌換鑽石

- 500 OC 金幣 → 100 OC 鑽石。
- 金幣不足時不能兌換。
- 每筆兌換都有交易紀錄；同一個交易編號重送不會重複扣款或重複增加鑽石。

### 鑽石商店與服飾收藏

- 商品分為帽子、眼鏡、上衣、褲子／裙子、鞋子、背部裝飾、其他裝飾。
- 每件商品都有實際的卡通人物圖層、名稱、稀有度、鑽石價格與能力增益。
- 稀有度由低到高：破爛、普通、超級、史詩，並有不同顏色的視覺標記。
- 購買前可預覽角色穿戴效果；購買後永久加入該學生的收藏。
- 商品目錄、價格與增益集中在 `server.js` 的 `SHOP_ITEMS`，可再調整。

### 穿戴系統

- 學生可在「我的服飾」穿戴、更換或脫下已擁有的服飾。
- 帽子、眼鏡、上衣、褲子、鞋子、背部裝飾、其他裝飾會顯示在角色對應位置。
- 穿戴狀態由伺服器保存，學生頁面與教師看到的角色一致。
- 伺服器會檢查服飾是否屬於該學生，以及是否穿在正確部位。

### 寶箱抽獎

- 每次抽獎 60 OC 鑽石，結果完全由伺服器隨機決定。
- 抽獎前檢查鑽石是否足夠；每次抽獎都保存結果與紀錄。
- 可以抽到重複服飾，重複會累計為額外收藏數量。
- 同一個抽獎編號重送不會重複扣鑽石或重複發放。
- 各稀有度權重集中在 `server.js` 的 `CHEST_WEIGHTS`，可再調整。

### 五種能力

- 每位學生有想像力、智力、誠實、努力、態度五種能力，與等級、經驗值、金幣、鑽石分開管理。
- 能力 = 作業累積的基礎值 + 目前穿戴服飾的即時增益。
- 脫下服飾會移除該服飾的增益；更換服飾時由伺服器重新計算，不會重複累加。
- 學生不能自行修改能力或服飾增益。

### 作業能力獎勵

- 個別作業與全班作業的派發表單都有「＋ 新增能力增益」按鈕。
- 可選擇一種或多種能力，分別設定增加數值；也可以完全不設定。
- 學生完成作業後，經驗值、OC 金幣與能力增益只發放一次。
- 能力增益與領取紀錄保存在伺服器。

## 第四版功能：3D 房子、家具與自由探索

### OC 房子入口與命名

- 學生登入後，可從右上角三條槓選單進入「🏠 OC 房子」。
- 第一次進入時，會先請學生替自己的房子取名字（1～12 個字）；名字會顯示在房子旁的木牌與畫面上方。
- 房子是每位學生獨立的私人空間：沒有訪客功能、不會連到其他同學，也不會出現在班級畫面中。
- 房子名稱、房屋外觀、家具佈置與解鎖狀態都保存在伺服器，重新登入或換裝置後仍然存在；可隨時按「✏️ 改名」修改。
- 房子資料只開放給本人：所有 `/api/house` 相關端點都要求學生身分，且只會讀寫自己的資料。

### 3D 場景

- 使用本機提供的 Three.js r186（`public/vendor/three.module.js`），以 `WebGLRenderer`、透視攝影機、方向光／半球光、陰影與 `MeshStandardMaterial` 建立場景，不使用 CDN 或舊版 API。
- 場景包含綠色草原、天空、雲朵、遠山與自然光影；房屋、家具與裝飾品全部由程式化幾何模型組合，沒有外部模型授權或載入速度問題。
- 程式碼模組化：`scene.js`（環境與房屋）、`furniture.js`（家具模型）、`editor.js`（建造編輯器）、`player.js`（第一人稱控制器）、`index.js`（進出場與模式切換）、`preview.js`（3D 縮圖、模型檢視器、房屋檢視器）。
- 陰影貼圖、像素比與物件數量都有上限；每間房子最多 80 個物件，兼顧手機與 iPad 的效能。
- **環境反射**：使用 PMREMGenerator 產生環境貼圖，金屬、玻璃、鏡面材質可反映天空與環境。
- **程式化貼圖**：木紋、布料、皮革、金屬、大理石、草地、地板、牆面皆以 Canvas 即時繪製，無外部圖片依賴。

### 建造模式

- 畫面右側有箭頭按鈕「›」，可展開／收起建造面板；面板分為「基本房屋」、「家具」、「裝飾品」、「其他物件」四類（**移除所有 Emoji**）。
- **圖片卡片式家具清單**：每件家具顯示真正的 3D 渲染縮圖（256×256 PNG，Base64 快取於 localStorage），點擊縮圖可開啟更大的 3D 模型預覽。
- 點選物件後在草原上點一下即可放置；放置前會顯示半透明預覽，綠色代表可以放、紅色代表超出範圍或撞到其他物件。
- 點選已放置的物件可重新選取，拖曳移動、用 ↺／↻ 旋轉、用 －／＋ 縮放（每種物件有各自的縮放上下限），按「刪除」或 Delete 刪除。
- **放大檢視按鈕**：選取家具後可點擊「放大檢視」，開啟獨立模型檢視器，支援拖曳旋轉、滾輪縮放、雙擊重置，不影響原本位置。
- 在空白草原拖曳可旋轉視角、滾輪可遠近縮放；手機選好物件後建造面板會自動收起，方便直接點草原放置。
- 房屋外觀只能選一種；家具必須完整放在屋內或完整放在屋外，不能跨牆；不可與牆壁、地板或其他實心物件重疊。
- 沒有解鎖的物件會顯示鑽石價格，需先購買才能使用；已解鎖的物件可自由重複擺放（仍受 80 件上限）。
- 每次變更後約 0.8 秒自動儲存，畫面顯示「有變更…／儲存中…／已同步 ✓／儲存失敗」；離開頁面時也會再送一次儲存。
- 按「完成，去逛逛」會先儲存，再切換到第一人稱探索模式；探索時不會誤移動家具。

### 第一人稱探索

- 電腦：進入探索模式自動鎖定滑鼠，用滑鼠環視，WASD 或方向鍵移動，Esc 放開滑鼠並回到 UI。
- 手機／iPad：左下虛擬搖桿移動，右側拖曳畫面環視；不需要鍵盤。
- 完整呈現 3D 房屋內部：牆壁、地板、天花板、門框、樓梯、家具、裝飾品皆可見。
- 可以自由進入房間、走廊及不同空間；走出家門到草原散步，也可以走回屋內。
- **完整碰撞檢測**：外牆、室內隔間牆、地板、天花板、門框、樓梯、家具、大型裝飾物皆有獨立碰撞盒。
  - 玩家不能穿過牆壁、家具、地板或掉出房屋。
  - 玩家可正常穿過已開啟的門（隔間門框已打開、大門半開）。
  - 家具碰撞箱精確符合模型實際大小（樹木、立燈、拱門、樓梯等有專用碰撞設定）。
  - 防止玩家卡進牆壁、家具或其他物件（卡住時自動推回合法位置）。
- 按「重新裝飾」隨時回到建造模式；屋頂與天花板只在探索模式顯示，編輯時會自動隱藏以便俯視佈置。

### 房屋模型放大檢視（新功能）

- 探索模式下點擊「檢視房屋」按鈕，或編輯模式雙擊房屋，進入大型模型檢視模式。
- 支援滑鼠滾輪縮放、左鍵拖曳旋轉、右鍵拖曳平移視角。
- 模型永遠不會消失或穿過檢視畫面（鏡頭近平面自動調整）。
- 提供「重置視角」（⟳）與「退出」（✕）按鈕。

### 家具獨立模型預覽（新功能）

- 建造面板點擊家具縮圖，或編輯模式選取家具後點「放大檢視」，開啟模態框。
- 獨立場景渲染，支援拖曳旋轉、滾輪縮放、雙擊重置、Esc 關閉、R 重置。
- 不影響原本房屋內家具的位置、旋轉、大小等狀態。

### 模型品質全面升級（新功能）

- **55 種家具/裝飾/建造物件**（原 32 種），新增：
  - 客廳：電視櫃、雲朵沙發、軟軟扶手椅
  - 臥室：雙人床、單人床、皇冠床、原木衣櫃
  - 書房：電腦桌、辦公椅、書書架、讀書桌
  - 廚房：雙門冰箱、微波爐、瓦斯爐、廚房櫥櫃
  - 餐廳：六人餐桌、餐椅
  - 衛浴：泡澡浴缸、洗手台、馬桶
  - 燈具與軟裝：星星立燈、落地窗簾、長方地毯、油畫掛框
  - 室內建造：室內隔間牆、隔間門框、木樓梯
  - 戶外裝飾：大盆栽、木框掛鐘
- **高品質材質**：
  - 木紋（淺色、中色、深色、白木）、布料（粉、藍、綠、紫、奶油、灰）、皮革（棕、深棕）
  - 金屬（銀、深灰、金）、大理石、陶瓷、鏡面、玻璃、螢幕發光材質
  - 燈光發光材質、水面、火焰、樹葉、岩石
- **真實比例**：所有家具尺寸符合真實家具比例（床寬 1.5～1.7m、冰箱高 1.8m、門寬 1.8m 等）。
- **光照陰影優化**：方向光 2048 陰影貼圖、半球光、環境光、門口補光、室內點光源、吊燈發光。
- **效能優化**：材質與貼圖全域快取共用、InstancedMesh 草叢、刪除時只釋放獨有幾何體、預覽縮圖離屏渲染並快取。

### 家具全擁有卡

- 右上角三條槓選單新增「家具全擁有卡」，也可從房子畫面右上角的「家具全擁有卡」進入。
- 價格 500 OC 鑽石；購買前會跳出確認視窗，明確告知這次要花費 500 鑽石。
- 鑽石不足時不能購買，畫面會顯示還差多少鑽石。
- 同一帳號只能購買一次；已擁有時顯示「✅ 已解鎖全部家具」，再次送出不會重複扣款。
- 購買後立即解鎖全部家具、裝飾品與可購買的房屋外觀；未來新增的物件是否包含在卡內，由伺服器常數 `ALL_CARD_INCLUDES_FUTURE` 統一決定。
- 鑽石扣款、解鎖清單與購買紀錄全部由伺服器處理，前端只負責顯示。

### 房子 API

| 方法 | 路徑 | 說明 |
| --- | --- | --- |
| GET | `/api/house` | 取得自己的房子（名稱、外觀、物件、解鎖狀態、卡片狀態） |
| POST | `/api/house/name` | 第一次命名或重新命名（1～12 字） |
| GET | `/api/house/catalog` | 取得物件目錄、分類、價格、尺寸與全擁有卡設定 |
| POST | `/api/house/save` | 儲存整間房子的外觀與所有物件（伺服器重新驗證範圍、重疊與解鎖狀態） |
| POST | `/api/house/buy-item` | 用鑽石解鎖單一物件（需 `requestId`，重送不會重複扣款） |
| POST | `/api/house/all-card` | 購買家具全擁有卡（500 鑽石，每帳號一次，需 `requestId`） |

房子資料存在 `data/db.json` 的 `students[].house`：`name`、`model`、`items[{ uid, itemId, x, z, rot, scale }]`、`unlocked[]`、`cardPurchased`、`cardPurchasedAt`、`layoutUpdatedAt` 等；購買紀錄另存於 `housePurchaseLogs`。

## 安全性說明

- 所有登入驗證、班級資料、交易、抽獎、能力與穿戴狀態都由伺服器處理。
- 教師與學生的權限在伺服器端檢查（`requireTeacher` / `requireStudent`），不能只靠前端按鈕隱藏。
- 工作階段使用 HttpOnly Cookie，登入號碼不會寫入網址。
- 學生只能取得自己的完整收藏與能力資料；教師可查看全班。
- 購買、兌換、抽獎與作業獎勵都有重複送出保護。
- 房子相關端點只允許本人存取；物件價格、解鎖狀態、擺放範圍與碰撞都由伺服器重新驗證，不能只靠前端程式判斷。

```

public/style.css   淡紫、奶油黃、淺藍的圓角卡通風格
public/app.js      畫面切換、API 呼叫、卡通人物與服飾圖層、家具預覽模態框
public/house3d/    Three.js 場景、家具模型、建造編輯器、第一人稱控制器
  index.js         場景組裝、模式切換、Inspector/Viewer 整合
  scene.js         草原、天空、光照、環境貼圖、房屋外觀、程式化貼圖
  furniture.js     55 種程序化高細節家具模型、材質、貼圖、獨立碰撞盒
  editor.js        放置、移動、旋轉、縮放、刪除、自動儲存、雙擊檢視、房屋點擊
  player.js        第一人稱 WASD/搖桿移動、滑鼠/觸控視角、完整碰撞檢測
  preview.js       PreviewStudio（3D 縮圖）、ItemInspector（家具檢視）、HouseViewer（房屋檢視）
public/vendor/     本機 Three.js r186 模組
data/db.json       伺服器端資料（執行後自動建立）
```

## 後續可調整項目

- `SHOP_ITEMS`：商品名稱、稀有度、價格、能力增益與外觀參數。
- `HOUSE_ITEMS`：房屋／家具／裝飾品的名稱、分類、價格、尺寸、縮放範圍與是否為實心物件（現有 55 種，含隔間牆、門框、樓梯等建造物件）。
- `LOCAL_COLLIDERS`（`furniture.js`）：各模型的精確碰撞盒設定，可微調。
- `ALL_CARD_PRICE`、`ALL_CARD_INCLUDES_FUTURE`：家具全擁有卡價格，以及是否包含未來新增物件。
- `HOUSE_MAX_ITEMS`、`HOUSE_AREA`：每間房子的物件上限與可建造範圍。
- `CHEST_COST_DIAMONDS`、`CHEST_WEIGHTS`：寶箱價格與各稀有度機率。
- `EXCHANGE_COST_COINS`、`EXCHANGE_GAIN_DIAMONDS`：兌換比例。
- 能力初始值、上限與升級規則目前未設上限，可再規劃。
- 陰影貼圖解析度（`scene.js` 的 `shadowSize`）、像素比上限可依裝置調整。
- 縮圖快取版本（`THUMB_CACHE_KEY`），更新模型後可改版本號使所有用戶重新生成。
